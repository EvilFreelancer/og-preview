NeuralDeep — LLM-прокси для ваших агентов и проектов

Что это: единый OpenAI-совместимый API к языковым моделям (LLM): qwen, эмбеддинги, реранк и whisper развёрнуты на собственных GPU в РФ, остальной каталог идёт через внешних вендоров (регион обработки помечен у каждой модели). Это LLM-прокси/шлюз и платформа — НЕ генератор картинок и НЕ 3D-сервис. Один sk- ключ, base URL https://api.neuraldeep.ru/v1, совместим с OpenAI SDK, opencode, Cursor, Cline, Continue, LangChain и любыми OpenAI-клиентами — свои агенты и боты подключаются без переписывания кода. Оплата в рублях, без VPN и зарубежных карт.

Чем отличается от перепродавцов токенов: основные модели крутятся на нашем собственном железе (не реселл зарубежного API), и данные по ним остаются на нашей инфраструктуре (152-ФЗ); оплата — месячной подпиской, а не посуточным счётом за токены.

Модели

  • DaisyGPT (на базе Qwen 3.6, 35B-A3B) — чат, инструменты, reasoning, vision, 256k контекст
  • GPT-OSS 120B — чат, инструменты, reasoning, 131k контекст · внешний вендор, обработка вне РФ
  • Gemma 4 31B — чат, мультимодальность, 262k контекст · внешний вендор, обработка вне РФ
  • Kimi K2.6 — внешняя топовая модель (платные тарифы)
  • Embeddings: e5-large, bge-m3, jina-v4, GigaEmbeddings · Rerank: bge-reranker · Whisper: транскрипция аудио

На бесплатном тарифе доступны только открытые модели — DaisyGPT (Qwen 3.6) и GPT-OSS 120B. Премиум-модели (GLM, DeepSeek, MiniMax, Kimi — до 1M контекста) — по подписке или с оплатой по токенам (кошелёк PAYG).

Сервисы платформы

  • LLM API — chat, embeddings, rerank, transcription, vision
  • Drift — персональный AI-агент с памятью, песочницей для кода и Telegram
  • Search API — веб- и Telegram-поиск, краулинг
  • SpeechCore — транскрипция длинных аудио/видео (WhisperX) + синтез речи (TTS)
  • OCR API — PDF/скан → markdown
  • Image API — генерация/апскейл/удаление фона
